## Open bug — QuicCidLifecycle SIGSEGV (loop 5)

Repro:

    MACHGATE_KEEP_CRASH_HANDLER=1 MACHGATE_TRACE_SIGNALS=1 \
      /home/coder/git/roblox/machgate/bin/repro-test.sh RbxTransportProtocol \
      '--run_test=QuicCidLifecycle/server_close_unregisters_cids_from_dispatcher'

Crash signature (from machgate FP-chain diagnostics):

    SIGSEGV code=1 addr=0x60000 pc=SysEventLoop::processPendingIoCallbacks+0x54
    insn: blr x9 / ldr x0, [x8, #0x8] with x8 = ev->h = 0x5fff8

Disassembly shows the fault is in the FIRST loop of
processPendingIoCallbacks (poller->popEvent() result usage):
ev->h is a garbage handle pointer. The engine's poller records are
identified by kevent udata; suspicion was a stale-udata delivery
(registration deleted/reused with a new udata while a poll snapshot
was in flight). A drop-if-udata-changed guard was added in
emit_kqueue_events but the crash persists — so either the theory is
wrong or there is a second path (consider: registration slot reuse
with same udata value, alias map in remember_kqueue_fd, the kqueue fd
being closed while a kevent is mid-poll, or genuine engine-side UAF
that macOS timing hides).

Next steps for the loop:
1. Re-run with MACHGATE_FD_TRACE_FILE and correlate which
   kevent_change/EV_DELETE for ident=8 interleaves with the crash
2. Instrument emit_kqueue_events to log dropped-stale events and
   verify the guard actually fires
3. If udata delivery is proven correct, pivot: dump the poller event
   record memory at crash time (fp[0] = runOncePriv+0x194 gives the
   frame; walk the SysPoller state) or run the suite under the
   container's lldb (llvm-18 present in machgate-arm64-toolchain image)
4. Related CI evidence: glibc heap-corruption asserts
   (old_top == initial_top) hint the same corruption class

## Tooling facts (learned the hard way)

- Catch2 v3.10 args must use the = form: '--run_test=X=Y'; the
  space form silently runs the whole driver; --deselect and ~
  exclusion DO NOT work in this build — use comma-separated positive
  specs ('--run_test=SuiteA/*,SuiteB/*')
- bin/repro-test.sh passes extra args via bash -c "$@" (fixed);
  auto-prefers the optimized corpus dir; passes MACHGATE_* env vars
- Rebuild the shim:
  docker run --rm --platform linux/arm64 -v /home/coder/git/roblox/machgate:/work -w /work \
    machgate-arm64-toolchain cmake --build build-arm64 --parallel
- binfmt (arm64 emulation on x86_64 devspace) drops after reboot:
  docker run --privileged --rm tonistiigi/binfmt --install arm64
- Full corpus driver run (no exclusions possible): expect SIGSEGV at
  QuicCidLifecycle killing the rest — use positive suite lists instead
- Single-test symbolization works inside the container:
  /usr/lib/llvm-18/bin/llvm-symbolizer --obj=<binary> <addr>
  (llvm-18 also has llvm-objdump, nm; Linux nm cannot parse Mach-O)
- macOS SDK reference headers:
  ~/.pkg_cache/xcode-sdk-macosx/26.2.../MacOSX.sdk/usr/include
  (IPPROTO_IP=0, IP_DONTFRAG=28, struct kevent 48B, msghdr 48B)
- Darwin kernel source: ~/git/roblox/apple-oss-reference/xnu
